# Database Management System

SQLite-driven employee manager with authentication.

## Features
- User registration and login
- Password hashing (PBKDF2 + salt)
- Role-based access (first user = admin)
- CRUD, search, filters, reports
- Database backup (admin)

## Technologies
Python 3, SQLite, hashlib

## Setup & Run
```bash
python main.py
```

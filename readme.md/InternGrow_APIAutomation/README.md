# REST API & Automation

Scripts that consume APIs and automate tasks.

## Features
- Consume public REST APIs (Open-Meteo, JSONPlaceholder)
- GET/POST requests, JSON parsing
- Weather dashboard
- Email automation (set EMAIL_USER / EMAIL_PASS env vars)
- File automation (organize folder by type)
- Web scraping with BeautifulSoup
- Scheduled jobs and API error handling

## Technologies
Python 3, requests, BeautifulSoup

## Setup & Run
```bash
pip install -r requirements.txt
python main.py
```

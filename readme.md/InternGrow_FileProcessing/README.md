# File & Data Processing System

Python app for file and data management.

## Features
- Read, write, update, delete text files
- CSV processing with summary stats
- Excel reading (OpenPyXL)
- PDF report generation (ReportLab)
- Logging to app.log
- Automatic backups in backups/

## Technologies
Python 3, csv, openpyxl, reportlab, logging

## Setup & Run
```bash
pip install -r requirements.txt
python main.py
```

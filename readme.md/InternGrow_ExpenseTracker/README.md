# Expense Tracker (Desktop App)

Tkinter desktop app with SQLite.

## Features
- Login and registration (hashed passwords)
- Dashboard with total spending
- Add, update, delete expenses
- Search and category filter
- Spending chart
- Export to CSV and PDF

## Technologies
Python 3, Tkinter, SQLite, ReportLab

## Setup & Run
```bash
pip install -r requirements.txt
python main.py
```

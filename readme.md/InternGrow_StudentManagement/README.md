# Smart Student Management System

Console-based student manager with JSON storage.

## Features
- Add, update, delete, search students
- Automatic grade calculation (A+ to F)
- JSON data storage
- Input validation and exception handling
- Menu-driven interface

## Technologies
Python 3, OOP, JSON

## Setup & Run
```bash
python main.py
```
